The Unlikely Review

How the unlikely happened.

Cinematic story documentaries about the frauds, inventions, empires and accidents that should never have worked, and sometimes did.

The Unlikely Review is an independent YouTube channel. Every film follows one true story, built from published sources and archival material, told in one consistent voice and visual style. The subjects range across crime and scams, business, history, science and places. Each film's sources are listed in its description.

Watch on YouTube: @TheUnlikelyReview

About the "Unlikely Review" application

"Unlikely Review" is also the name of a small private software tool that the channel owner uses to run his own channel. It uses YouTube API Services (the YouTube Data API v3 and the YouTube Analytics and Reporting APIs) to:

  • upload videos, thumbnails, captions and video details to The Unlikely Review channel, and organise them into playlists;
  • read performance analytics for that channel's videos (for example views, watch time, impressions and click-through rate), so the owner can decide what to make next.

The tool acts only on the channel owner's own YouTube channel, after he has signed in with Google and granted permission. It is not offered to the public, and it doesn't access any other user's account. Videos are only made public when the owner chooses.

By using this application you agree to be bound by the YouTube Terms of Service. How the application handles Google user data is described in the Privacy Policy.
