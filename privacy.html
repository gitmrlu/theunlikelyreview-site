The Unlikely Review

Privacy Policy

Application: "Unlikely Review" · Effective date: October 8, 2026 · Last updated: October 8, 2026

1. Who we are and what this covers

"Unlikely Review" (the "Application") is a private software tool operated by the owner of the YouTube channel The Unlikely Review (the "Owner", "we"). The Owner uses it to publish videos to, and read analytics for, that one channel. It is not offered to the public. The only Google account that is meant to authorize it is the Owner's own account for The Unlikely Review channel.

This policy explains what Google user data the Application accesses, how it is used, stored, shared and deleted, and how to revoke access. Viewers who watch our videos on YouTube are covered by YouTube's and Google's own policies, not this one. The Application does not collect any data about viewers as individuals.

2. The Application uses YouTube API Services

The Application uses YouTube API Services, specifically the YouTube Data API v3, the YouTube Analytics API and the YouTube Reporting API. By using the Application you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. What data the Application accesses

With the authorizing user's permission (Google OAuth), the Application requests only these scopes:

ScopeWhy
youtube.uploadTo upload the Owner's videos to the Owner's channel.
youtubeTo manage those videos after upload: set titles, descriptions, thumbnails, captions, scheduling and visibility, and add videos to playlists.
yt-analytics.readonlyTo read analytics reports for the Owner's channel through the YouTube Analytics and Reporting APIs.

Through these scopes the Application accesses:

  • Channel and video information for the authorized channel: channel ID and name, the channel's uploaded videos, and their titles, descriptions, thumbnails, captions, playlists, privacy status and publish schedule.
  • Channel and video analytics (aggregated statistics provided by YouTube): for example views, watch time, average view duration and percentage, impressions and click-through rate, subscribers gained or lost, traffic sources and audience retention. These are aggregate figures. They don't identify individual viewers.
  • OAuth tokens issued by Google, which let the Application act on the authorized channel without storing a password. The Application never sees or stores the user's Google password.

The Application doesn't request access to Gmail, Google Drive, contacts or any other Google service. It doesn't read comments, messages, other users' private data, or anything from channels other than the authorized one.

4. How the data is used

Google user data is used only to provide the Application's features to the Owner:

  • uploading and managing videos on The Unlikely Review channel. Videos are uploaded as private or scheduled, and a video is made public only when the Owner chooses;
  • producing internal performance reports for the Owner (for example, which videos and topics perform best), so the Owner can plan future videos.

Google user data is not used for advertising, isn't sold, isn't used to build user profiles, and isn't used to develop, improve or train generalized artificial-intelligence or machine-learning models. The Application's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

5. How the data is shared

We don't sell, rent, trade or share Google user data with third parties. The data is available only to the Owner and to software running on the Owner's private server on the Owner's behalf. The only exceptions are where disclosure is required by law, or where it's necessary to protect against fraud, abuse or security threats. The Application doesn't allow third parties to serve content or advertisements, and doesn't use third-party analytics.

6. How the data is stored and protected

  • OAuth tokens and analytics data are stored on a private server controlled by the Owner, in files and a local database readable only by the Owner's account. They're transmitted only over encrypted (HTTPS) connections to Google.
  • OAuth credentials are kept out of source code and public repositories.
  • The Application doesn't place cookies or similar tracking technology on anyone's browser or device. This website doesn't use cookies, analytics or trackers either.

7. Retention and deletion

  • Analytics data (from the YouTube Analytics and Reporting APIs) is kept only as long as it's needed to produce the Owner's performance reports. As YouTube's policies require, the Application checks at least every 30 days that it is still authorized, and deletes analytics data if authorization has ended.
  • Other YouTube data (such as video metadata lists) is refreshed or deleted within 30 days.
  • OAuth tokens are kept only while the Owner uses the Application, and are deleted when access is revoked.
  • If access is revoked, all Google user data obtained through that authorization is deleted as soon as possible and no later than 7 days after revocation. The Application also revokes its tokens with Google.
  • Videos uploaded to YouTube stay on YouTube under the channel owner's control and can be managed or deleted in YouTube Studio.

8. How to revoke access

You can remove the Application's access to your Google account at any time from your Google Account permissions page: https://myaccount.google.com/permissions. This is the same page YouTube's policies refer to as https://security.google.com/settings/security/permissions. Select "Unlikely Review" and choose to remove access. Stored data is then deleted as described in section 7. You can also ask for deletion at any time using the contact below.

9. Children

The Application isn't directed to children and doesn't knowingly collect data from children.

10. Changes to this policy

If the Application starts to access or use Google user data in a new way, we'll update this policy first and ask for consent again before doing so. The effective date above shows the latest version.
